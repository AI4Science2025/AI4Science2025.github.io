Research

PoseWords: Mobility-Aware 3D Molecular Tokenization and Generation
Ongoing · Jul 2026 – present
Investigating molecular topology and geometry representations for peptide-conditioned ligand generation — how discrete encodings capture 2D connectivity and 3D conformations together. Built a mobility-aware tokenizer with fragment conformer quantization, achieving 653% greater fragment reuse, 41% fewer single-atom tokens and 14% shorter sequences than a rule-based baseline. Developing an SE(3)-aware generative framework with torsion-based geometry and chemically constrained fragment assembly, with controlled evaluation and geometric error analysis guiding representation redesign.
BiScale-GTR: Fragment-Aware Graph Transformers for Multi-Scale Molecular Representation
Accepted at TMLR · Oct 2025 – Jul 2026
A self-supervised, fragment-aware graph Transformer combining GINE atom encoders, attention pooling, gated atom–fragment fusion and a structure-aware Transformer for multi-scale molecular representation learning. A deterministic RDKit graph-BPE pipeline with WL hashing, chemical-validity filtering and recursive OOV decomposition improves Peptides-func AP from 0.632 to 0.672 and Peptides-struct MAE from 0.293 to 0.262, using 78.5% less pretraining data than 2M-molecule baselines.

Interpretable ML for Organic Photovoltaic Property Prediction
Published · Sep 2024 – Aug 2025
An end-to-end explainable XGBoost pipeline over 350 donors and six acceptors: curating molecular data, computing 2,000+ descriptors and predicting photovoltaic performance at test R² = 0.918. Feature selection, SHAP-based attribution and external-dataset validation identified 10 interpretable predictors and quantified model transferability beyond the training distribution.

Projects

HELP-E: Long-Horizon LLM Context & Memory System
with Maitry Bhavsar and Xinpeng Li · Mar 2026 – Oct 2026
Built an emotional-support dialogue system that tracks multiple interrelated user concerns across sessions using a theory-grounded graph memory — Health Belief Model attributes, Transtheoretical Model stages, and Motivational Interviewing strategies — over a Llama-3.3-70B backbone. Designed a profile-driven multi-session user simulator (30 profiles × 4 sessions × 10 turns) and an ablation suite spanning a history-only baseline to a full typed-graph tracker. The structured graph memory raised active-concern detection to 0.668 F1 (+38.3% over a summary-only baseline) while preserving high support quality (MITI 4.57 / ESC 4.90). Built as a containerized, FastAPI-based multi-agent system over OpenAI-compatible vLLM serving, with model-aware context management (token-budgeted assembly, evidence prioritization, exact/semantic deduplication, provenance-preserving compression) and MiniLM/MMR retrieval. Instrumented for observability — stage latency, inference throughput, process/GPU memory, context-token consumption and retries — with reproducible JSON audit traces. Benchmarking across 2K–16K context budgets over 2,100 turns and 15 profiles improved assigned-primary detection from 60% to 73%.

NLP for Web Security: HTTP Attack Detection with DistilBERT
Dallas, TX · May 2025 – Jul 2025
Treated web-attack detection as an NLP classification problem. Used SQL to retrieve and filter HTTP request logs, then engineered 12 security-focused features and character n-gram TF-IDF representations from 18,211 requests for a four-class attack classification. Benchmarked logistic regression, SVM, random forest and DistilBERT, achieving 0.84 macro F1 with DistilBERT against 0.815 with a linear SVM.
